Регистрация вебхука

Серверный скрипт для SimpleOne — создаёт/обновляет системные свойства для Telegram-прокси

Как использовать

1. Скопируйте скрипт выше

2. В вашем экземпляре SimpleOne перейдите в Серверные скрипты (sys_script)

3. Создайте новый скрипт и вставьте скрипт выше

4. Выполните скрипт

Скрипт создаст свойства, если их нет, или обновит значения, если они уже существуют.

Устанавливаемые свойства:

  • itsm.telegram_bot.url — URL HTTP-прокси для исходящих вызовов Telegram API
  • vcsm.telegram_bot.url — URL HTTP-прокси для исходящих вызовов Telegram API (VCSM)
  • itsm.telegram_bot.webhook_url — URL HTTPS-прокси для регистрации входящих вебхуков
  • vcsm.telegram_bot.webhook_url — URL HTTPS-прокси для регистрации входящих вебхуков

Важно: Свойства в разных приложениях могут быть отредактированы только в этих приложениях либо с правами vendor.
